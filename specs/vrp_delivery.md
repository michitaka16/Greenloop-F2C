# VRP Delivery Routing — Domain Specification

## Overview

VRP (Vehicle Routing Problem) optimizes last-mile delivery routes for the the farm.
It sits at Layer 4 alongside the retail segmentation module, consuming Layer 2 optimizer
output and producing delivery routes for the 3-truck fleet.

**Scope:** Capacitated VRP with Time Windows (CVRPTW) using OR-Tools native solver.
**Module:** `src/greenloop/layer2b/vrp_solver.py`
**Map:** Folium + streamlit-folium (not Plotly)

#### Customer
```python

class Customer:
```

Priority weights used for demand disaggregation:
- Priority 1 (supermarkets): weight = 3
- Priority 2 (restaurants): weight = 2

#### DeliveryRequest

## VRP Solver Contract

### Signature
```python
def solve_vrp(
    deliveries: list[DeliveryRequest],
    vehicles: list[Vehicle],
    depot: Depot,
    customers: list[Customer],
    distance_matrix: list[list[float]],  # haversine km between all points
    time_window_hours: int = 12,        # delivery window (12 normal, 6 typhoon)
    max_time_seconds: float = 3.0,
) -> VRPSolution:
    """Solve CVRPTW. Returns VRPSolution. Raises InfeasibleError if no solution."""
```

### Objective Function
```
Minimise: Σ(distance_km × fuel_cost_per_km) + Σ(driver_hours × wage_per_hour)

fuel_cost_per_km = 0.25 SGD/km
driver_wage_per_hour = 15.0 SGD/hour
```

### Constraints

| Constraint | Type | Implementation |
|-----------|------|----------------|
| Vehicle capacity | Hard | OR-Tools capacity dimension (200kg per vehicle) |
| Time windows | Soft | Penalty callback for arrivals outside window |
| MOM shift limit | Hard | shift_end - shift_start ≤ 8 hours |
| Depot start/end | Hard | All routes start and end at depot |

### Haversine Distance
```python
def haversine(lat1, lng1, lat2, lng2) -> float:
    """Great-circle distance in km."""
    R = 6371  # Earth radius in km
    dlat = radians(lat2 - lat1)
    dlng = radians(lng2 - lng1)
    a = sin(dlat/2)**2 + cos(lat1) * cos(lat2) * sin(dlng/2)**2
    return R * 2 * asin(sqrt(a))
```

### Travel Time
```python
def travel_time_hours(distance_km) -> float:
    """Average speed 30 km/h in Singapore urban conditions."""
    return distance_km / 30.0
```

## Layer 2 → VRP Disaggregation

### `optimizer_to_deliveries()` Contract

```python
def optimizer_to_deliveries(
    plan: dict,           # Layer 2 build_and_solve() output
    forecast: dict,       # Layer 1 predict_demand() output
    customers_df: pd.DataFrame,
    date: date,
) -> list[DeliveryRequest]:
```

### Algorithm

1. **Count tiers per crop** from `plan["rack_layout"]`: `{crop_id: tier_count}`
2. **Compute kg per crop**:
   ```
   kg_per_crop = forecast[crop_id]["upper_ci"] * (tiers_per_crop[crop_id] / 10) * (1 - spoilage_rate)
   ```
3. **Distribute to customers** by priority weight:
   ```
   total_weight = Σ(priority_weight[priority])
   customer_share = kg_per_crop * (priority_weight / total_weight)
   ```
4. **Split across crop types** (supermarkets = mixed greens; restaurants prefer herbs)
5. **Return** list of DeliveryRequest

## Typhoon Scenario

### Normal Mode (12h window)
- `time_window_hours = 12`
- All 30 deliveries served across N routes

### Typhoon Mode (6h window)
- `time_window_hours = 6`
- VRP re-solves with 6h constraint
- Tight time windows (especially restaurants 10am–14pm) may become unschedulable

### Session State Integration
- `st.session_state.typhoon_active = True` set by app.py typhoon button
- Page 4 reads this flag and passes `time_window_hours=6` to solver

### Display Contract
```
Normal:  "✓ All 30 deliveries scheduled | 115km | $28.40 | 847ms"
Typhoon feasible: "✓ All 30 deliveries scheduled in 6h window | 98km | $24.20"
Typhoon infeasible: "⚠ 5 deliveries unscheduled: C012 FairPrice Jurong West, C018 Hawker Centre Pioneer, +3 more"
```

## Map Visualization

### Folium Map Specification

```python
import folium
from streamlit_folium import st_folium

def render_vrp_map(solution, depot_lat, depot_lng, customers_df) -> folium.Map:
    m = folium.Map(
        location=[depot_lat, depot_lng],
        zoom_start=12,
        tiles="OpenStreetMap",
    )

    # Depot marker
    folium.Marker(
        [depot_lat, depot_lng],
        popup="Adopt a Kale Farm — Jurong Innovation District Depot",
        icon=folium.Icon(color="blue", icon="home"),
    ).add_to(m)

    # Customer markers colored by route
    route_colors = {0: "red", 1: "blue", 2: "green", 3: "purple", 4: "orange"}
    for cid, route_idx in solution["vehicle_assignments"].items():
        row = customers_df[customers_df["customer_id"] == cid].iloc[0]
        folium.CircleMarker(
            [row["lat"], row["lng"]],
            radius=8,
            color=route_colors.get(route_idx, "gray"),
            fill=True,
            popup=f"{row['name']}\nTime window: {row['tw_start']}–{row['tw_end']}\n{row['weekly_kg']} kg/week",
        ).add_to(m)

    # Route polylines (depot → customers → depot)
    colors = ["red", "blue", "green", "purple", "orange"]
    for route_idx, route_customer_ids in enumerate(solution["routes"]):
        coords = [[depot_lat, depot_lng]]  # start at depot
        for cid in route_customer_ids:
            row = customers_df[customers_df["customer_id"] == cid].iloc[0]
            coords.append([row["lat"], row["lng"]])
        coords.append([depot_lat, depot_lng])  # return to depot
        folium.PolyLine(coords, color=colors[route_idx % len(colors)], weight=3, opacity=0.7).add_to(m)

    return m
```

## Error Handling

| Error | Display |
|-------|---------|
| VRP infeasible | `st.warning()` with unassigned customer names |
| OR-Tools timeout | `st.warning()` + partial solution if any |
| Zero deliveries | `st.info()` — "No deliveries to schedule" |
| Distance matrix computation error | `st.error()` + fallback to straight-line estimate |

---

## Edge Cases

1. **Zero production day**: Layer 2 produces 0kg → VRP receives empty delivery list → show "No deliveries today"
2. **Demand exceeds fleet capacity**: `is_feasible=False` with `unassigned` list — warn user, suggest splitting delivery across days
3. **All customers same location**: Distance matrix has 0s — solver handles this, routes collapse to single-point visits
4. **Restaurant tight window conflict**: Two restaurants with 7:00–9:30 windows at opposite ends of Singapore — solver may assign one to a later truck — shown as "late" in the violations dict
